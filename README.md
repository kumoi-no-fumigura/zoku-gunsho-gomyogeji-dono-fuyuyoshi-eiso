## 作品について

関白一条冬良（後妙華寺）の詠草。永正5年（1508）正月の月次など、二楽（飛鳥井雅康）の出題による歌を月ごとに収める。奥書に、冬良の自筆に紛れないとある。

## 本文の作り方

国立公文書館の公開画像を、国立国会図書館の NDL古典籍OCR-Lite でテキスト化し、原本のページごとに段落に分けました。写本の崩し字の OCR なので、誤りが多く残っています。

## ファイル

| パス | 中身 |
